# Scoring Methods Reference

The exact formulas for converting vendor responses into numbers. Apply the formula that the RFP specified — never invent a different method.

## Quick rule

The scoring formula must be **identical** to what the RFP published. If the published method is "יחסי", use יחסי. If "מוחלט", use מוחלט. Don't blend them. The scoring committee can be challenged later if the math doesn't match the published rules.

## Method 1 - יחסי (Relative scoring)

The most common method. Each criterion is scored relative to the best vendor.

### For criteria where higher is better (experience, references):

```
ניקוד הספק = (ערך הספק / הערך הטוב ביותר במכרז) × ניקוד מקסימלי
```

**Example**: קריטריון "ניסיון מוכח", משקל 10 נקודות.
- ספק א': 5 פרויקטים → הטוב ביותר → 5/5 × 10 = **10 נקודות**
- ספק ב': 4 פרויקטים → 4/5 × 10 = **8 נקודות**
- ספק ג': 3 פרויקטים → 3/5 × 10 = **6 נקודות**

### For criteria where lower is better (price):

```
ניקוד הספק = (הערך הטוב ביותר / ערך הספק) × ניקוד מקסימלי
```

**Example**: קריטריון מחיר, משקל 70 נקודות.
- ספק א': 4.2M ש"ח → 3.5/4.2 × 70 = **58.3 נקודות**
- ספק ב': 3.5M ש"ח → 3.5/3.5 × 70 = **70 נקודות**
- ספק ג': 5.0M ש"ח → 3.5/5.0 × 70 = **49.0 נקודות**

## Method 2 - מוחלט (Absolute scoring)

Each performance level gets a fixed score. Use when the RFP defines explicit thresholds.

**Example**: קריטריון "ניסיון מוכח", משקל 10 נקודות:
- 0-2 פרויקטים: 0 נקודות (פסילת תנאי סף)
- 3-4 פרויקטים: 5 נקודות
- 5-7 פרויקטים: 8 נקודות
- 8+ פרויקטים: 10 נקודות

```
ספק א': 5 פרויקטים → 8 נקודות
ספק ב': 4 פרויקטים → 5 נקודות
ספק ג': 3 פרויקטים → 5 נקודות
```

## Method 3 - שיטת השוואה (Comparison method)

Used in complex evaluations. Weighted comparison across multiple sub-criteria.

### Process:

1. **לכל סב-קריטריון** - דרגו את הספקים מ-1 (הטוב ביותר) ל-N (הגרוע)
2. **הפכו את הדירוג לניקוד**: ספק במקום 1 מקבל את הניקוד המקסימלי, ספק במקום N מקבל ניקוד מינימלי קבוע
3. **שקללו**: ניקוד הקריטריון × משקל הקריטריון

**Note**: שיטה זו פחות שקופה ולעיתים בעייתית בערעורים. השתמשו רק כשהמכרז דרש זאת בפירוש.

## Cost component formulas

### Standard formula (החישוב הנפוץ ביותר)

```
ניקוד מחיר = (המחיר הנמוך ביותר / מחיר ההצעה) × ניקוד מקסימלי
```

### Floor formula (עם sanity floor)

When the RFP includes a minimum-bid floor to prevent extreme underbids:

```
אם מחיר ההצעה < 0.7 × אומדן:
    הוועדה רשאית לדרוש הסבר; אם לא משכנע - פסילה
אחרת:
    ניקוד מחיר = (המחיר הנמוך ביותר / מחיר ההצעה) × ניקוד מקסימלי
```

### Hybrid formula (לחוזים ארוכי טווח)

For multi-year contracts where the price split is אמ-קופית בסכום קבוע + אמ-תפעולית שנתית:

```
מחיר משוקלל = מחיר חד-פעמי + (מחיר שנתי × N שנים × discount_factor)
ניקוד מחיר = (מחיר משוקלל הנמוך ביותר / מחיר משוקלל של הספק) × ניקוד מקסימלי
```

עם `discount_factor` של 0.85-0.9 לכיסוי NPV ושינויי שוק.

## Aggregating final score

לאחר חישוב ניקוד לכל קריטריון:

```
ניקוד סופי = Σ (ניקוד_קריטריון × משקל_קריטריון / 100)
```

**Example**:
```
ניקוד מחיר:           58.3  (משקל 70%)
ניקוד ניסיון:         10    (משקל 10%)
ניקוד CV:              8    (משקל 10%)
ניקוד מתודולוגיה:      4    (משקל 5%)
ניקוד NFR:             4    (משקל 5%)

ניקוד סופי = 58.3 × 0.7 + 10 × 0.1 + 8 × 0.1 + 4 × 0.05 + 4 × 0.05
           = 40.81 + 1.0 + 0.8 + 0.2 + 0.2
           = 43.01

```

⚠️ זהירות: לעיתים המכרז מציג את המשקלים כאחוזים (70%) ולעיתים כניקוד מקסימלי (70 נקודות). בדקו זאת לפני שאתם מתחילים את החישוב. ההפרש משמעותי.

## Common pitfalls

### Pitfall 1: רף מינימלי לניקוד איכות

לעיתים המכרז דורש שספק יקבל לפחות X נקודות באיכות כדי להתקדם לשלב המחיר. אם ספק לא עמד ברף - פסילה, גם אם המחיר הטוב ביותר.

```
אם ניקוד איכות < 18:
    פסילה
אחרת:
    חישוב ניקוד סופי
```

### Pitfall 2: ערך מחיר באמ"מ או כולל מע"מ

בדקו במפורש: האם ההצעות לפני מע"מ או אחרי? אם המכרז לא ציין - השוו את כולם לאותה רמה (לרוב לפני מע"מ).

### Pitfall 3: מחירים בשני מטבעות

אם הצעות הוגשו בש"ח ובדולרים - המירו את הכל לש"ח לפי שער יציב של בנק ישראל **בתאריך פתיחת ההצעות** (לא בתאריך ההגשה).

### Pitfall 4: עלות tco vs price

אם המכרז דורש Total Cost of Ownership (TCO) ולא רק מחיר רכישה - חשבו את כל המרכיבים: תחזוקה, רישוי שנתי, מערך תמיכה, השלכות על תשתית קיימת.

## Output format

הציגו את חישוב הניקוד בטבלה ברורה:

```
ספק א'                        ערך הספק    ניקוד     משקל    ניקוד משוקלל
==========================================================================
מחיר                          4.2M ש"ח    58.3      70%     40.81
ניסיון מוכח                   5 פרויקטים  10        10%     1.00
CV של ראש צוות                12 שנים     9         5%      0.45
CV של חברי צוות               7-9 שנים    8         5%      0.40
מתודולוגיה                    -           7         5%      0.35
הצעה טכנית / NFR              92% כיסוי   8         5%      0.40
==========================================================================
ניקוד סופי                                                  43.41
```

או בצורת רשימה:

```
ספק א' - ניקוד מפורט:
- מחיר (70%):                 58.3 / 70    →  40.81
- ניסיון מוכח (10%):           10 / 10    →  1.00
- CV ראש צוות (5%):             9 / 10    →  0.45
- CV חברי צוות (5%):            8 / 10    →  0.40
- מתודולוגיה (5%):              7 / 10    →  0.35
- NFR (5%):                     8 / 10    →  0.40
ניקוד סופי:                                  43.41
```

הציגו בשני הפורמטים - גם הוועדה (טבלה) וגם הדוקומנטציה הפנימית (רשימה מפורטת).
