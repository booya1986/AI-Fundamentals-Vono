## ניווט

- **`←` / `→`** או **`Space`** — מעבר בין שקפים
- **`F`** — מסך מלא
- **`Home` / `End`** — תחילת/סוף הדק
- **קליק על נקודה** בתחתית — מעבר ישיר לשקף
- **Swipe** במגע — שמאלה כדי להתקדם (RTL)
